## 📖 项目介绍
该项目是小红书APP端接口逆向学习工程，核心目标：
抓包小红书APP HTTPS请求 → 分析鉴权头 `x-s`（签名）、`x-t`（时间戳）、设备指纹、登录凭证 → 使用NodeJS实现签名生成逻辑 → 封装接口发起请求获取平台JSON数据。

项目分为四大模块：
- 签名模块：独立生成 `x-s`、`x-t`，可脱离网络单独调试、移植到Python/Go/Frida
- 配置模块：统一管理抓包所得Cookie、a1、设备指纹、密钥等敏感凭证
- API封装模块：组装请求头、封装搜索、笔记详情、评论等常用业务接口
- 测试入口：一键调用接口，调试签名连通性

> 重点：签名只是风控其中一环。就算签名完全正确，Cookie过期、设备指纹不匹配、IP异常、请求频率过高依然会返回403、412、-100等错误码。

## ✨ 功能清单
- ✅ NodeJS原生crypto实现签名工具函数
- ✅ 自动生成13位时间戳 `x-t`
- ✅ 统一Header组装，适配小红书APP请求格式
- ✅ 内置接口示例：关键词搜索笔记、笔记详情获取、笔记评论列表
- ✅ 请求延时控制，降低风控触发概率
- ✅ 模块化设计，签名函数可单独抽离复用
- ✅ axios请求封装，支持扩展HTTP代理

## 🧰 环境依赖
- Node.js >= 16（推荐 LTS 18 / 20）
- 内置 crypto（Node自带，无需额外安装）
- axios：用于发起HTTP请求
- 抓包工具：HttpCanary / Charles / mitmproxy
- 辅助逆向工具：Frida（用于Hook原生签名函数，对齐拼接原文）

安装依赖命令：
bash
npm install axios
